# עבודת שורשים אסתי

כאן נשמר כל מה שאסתי מוסרת בעל פה או בכתב במהלך המחקר — שמות, תאריכים, סיפורים
משפחתיים, עדויות ותיקונים.

## למה המחיצה הזאת קיימת

החומר שאסתי מכתיבה נשמר עד היום בתוך השיחה עצמה. שיחה ארוכה נושאת את כל התוכן
הזה מחדש בכל שאלה, וזה צורך כמות טוקנים גדולה.

מעכשיו החומר יושב כאן, ולא בדף השיחה.

## איך זה עובד

אסתי כותבת **"גיבוי אסתי"**.

ג'ורג' לוקח את כל מה שהיא מסרה מאז הגיבוי הקודם, שומר אותו כקובץ במחיצה הזאת,
ומעלה אותו לגיטהאב.

## שמות הקבצים

```
2026-11-17-ישראל-ישראלי.md
2026-11-17-עדות-סבתא-רות.md
```

תאריך, ואחריו נושא קצר בעברית.

## מה נשמר בכל קובץ

- **מה שאסתי אמרה** — כלשונו, בלי לקצר ובלי לפרש
- **התאריך** שבו נמסר
- **מי מסר**, אם היא ציינה מקור משפחתי

מה שג'ורג' מצא בעצמו במקורות **לא** נכנס לכאן. זה נכנס לכרטיסים באילן, עם
המקור שלו.

## הכלל

החומר הזה הוא **מסירה משפחתית**, לא ממצא מתועד. כשהוא נכנס לאילן — הוא מסומן
ככזה, בדיוק כמו שאר המקורות.
